# Agent — ایجنت محلی برای اجرای دستورات روی لپ‌تاپ

یک فایل پایتون، بدون هیچ نصب اضافه. بهش به زبان خودت می‌گی چی می‌خوای، خودش دستورات رو قدم‌به‌قدم می‌سازه و روی لپ‌تاپت اجرا می‌کنه.

## پیش‌نیاز

فقط **پایتون ۳.۸ به بالا** (روی ویندوز، مک یا لینوکس). هیچ کتابخانه‌ای لازم نیست.

## گرفتن کلید API رایگان

هیچ سرویسی کلید نامحدود رایگان نمی‌ده، ولی این‌ها ثبت‌نام رایگان و پلن رایگان واقعی دارن (یکی کافیه):

| سرویس | لینک کلید رایگان | متغیر محیطی |
|---|---|---|
| Google Gemini (پیشنهادی) | https://aistudio.google.com/apikey | `GEMINI_API_KEY` |
| Groq | https://console.groq.com/keys | `GROQ_API_KEY` |
| OpenRouter (مدل‌های free) | https://openrouter.ai/settings/keys | `OPENROUTER_API_KEY` |
| Mistral | https://console.mistral.ai/api-keys | `MISTRAL_API_KEY` |

کلید رو به‌صورت متغیر محیطی ست کن:

```bash
# لینوکس / مک
export GEMINI_API_KEY="کلید-تو"
```

```powershell
# ویندوز (PowerShell) — بعد از این دستور، ترمینال جدید باز کن
setx GEMINI_API_KEY "کلید-تو"
```

## اجرا

```bash
# حالت تعاملی (کارهای رو یکی‌یکی بگو)
python agent.py

# یا یک کار مشخص همون لحظه
python agent.py "تموم فایل‌های تکراری توی پوشه Downloads رو پیدا کن"

# حالت کاملاً خودکار: بدون سوال‌پرسی، هر دستوری رو مستقیم اجرا کنه
python agent.py -y "پوشه build رو پاک کن و دوباره بساز"

# حالت صوتی (وویس): حرف بزن، ایجنت گوش می‌ده و جواب رو بلند می‌گه
python agent.py --install-voice   # فقط بار اول: پکیج‌های صوتی رو نصب می‌کنه
python agent.py --voice -y
```

## نحوه کار

1. کار تو رو به مدل AI می‌فرسته.
2. مدل یک دستور برمی‌گردونه → ایجنت دستور رو **نشون می‌ده و اجازه می‌گیره** (مگر با `-y`).
3. خروجی دستور رو به مدل برمی‌گردونه و تا تموم شدن کار ادامه می‌ده (حداکثر ۳۰ قدم).

## گزینه‌ها

| گزینه | کار |
|---|---|
| `-y` / `--yes` | اجرای خودکار بدون تأیید هر دستور |
| `--voice` | حالت صوتی: گفتن کار با میکروفون، جواب صوتی |
| `--install-voice` | نصب پکیج‌های صوتی (`faster-whisper`, `sounddevice`, `pyttsx3`) |
| `-p groq` | تغییر سرویس (`gemini`, `groq`, `openrouter`, `mistral`) |
| `--model NAME` | مدل دلخواه |
| `--api-key KEY` | کلید بدون متغیر محیطی |
| `--timeout 300` | تایم‌اوت هر دستور (ثانیه) |
| `--max-steps 50` | سقف مراحل هر کار |

## قابلیت‌های ایجنت

- **برنامه‌نویسی و حل کد:** نوشتن، اجرا و دیباگ کد به هر زبانی
- **فایل‌ها:** ساخت، ویرایش، جست‌وجو، پاک‌سازی و سازمان‌دهی
- **بازی‌ها و برنامه‌ها:** نصب و اجرای هر اپ یا بازی
- **وب‌گردی:** دانلود فایل، خوندن صفحات، باز کردن مرورگر
- **نصب خودکار ابزار:** هر ابزاری که روی سیستم نباشه، خودش با apt/brew/choco/winget/pip نصبش می‌کنه
- **وویس:** ورودی صوتی فارسی/انگلیسی با Whisper (آفلاین) و جواب گفتاری با TTS آفلاین

## نکته امنیتی

حالت پیش‌فرض قبل از اجرای هر دستور ازت تأیید می‌گیره. با `-y` کنترل کامل به ایجنت می‌دی — روی کارهای حساس (پاک‌کردن فایل، تغییر تنظیمات سیستم) حواست باشه. همون‌طور که خودت خواستی این ابزار دسترسی کامل به لپ‌تاپ داره، پس فقط کارهایی بهش بده که خودت قبولشون هستی.
