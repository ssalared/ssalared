# 🤖 ایجنت — دستیار هوش مصنوعی محلی

ایجنتی که به زبان خودت (فارسی/انگلیسی، تایپی یا صوتی) کار می‌گیری و خودش دستورات رو قدم‌به‌قدم روی لپ‌تاپت اجرا می‌کنه: برنامه‌نویسی، فایل‌ها، نصب و اجرای بازی‌ها و برنامه‌ها، وب‌گردی، و نصب خودکار هر ابزاری که لازم داشته باشه.

## فایل‌ها

| فایل | کار |
|---|---|
| `agent.py` | کل ایجنت در یک فایل: حالت متنی + وویس + سایت وب با دو اتاق |
| `START-WINDOWS.bat` | ویندوز: دابل‌کلیک کن، منوی اجرا میاد |
| `START-MAC-LINUX.sh` | مک/لینوکس: دابل‌کلیک (یا `sh START-MAC-LINUX.sh`) |
| `.gitignore` | فایل‌های موقتی که نباید کامیت بشن |

## راه‌اندازی سریع

۱. **کلید API رایگان** (یکی کافیه):
   - Google Gemini (پیشنهادی): https://aistudio.google.com/apikey
   - Groq: https://console.groq.com/keys

۲. **ست کردن کلید:**
   ```powershell
   # ویندوز (PowerShell) — بعدش ترمینال جدید باز کن
   setx GEMINI_API_KEY "کلید-تو"
   ```
   ```bash
   # لینوکس / مک
   export GEMINI_API_KEY="کلید-تو"
   ```

۳. **اجرا:**

   راحت‌ترین راه: دابل‌کلیک روی فایل START.

   یا توی PowerShell / ترمینال، توی همین پوشه:
   ```bash
   python agent.py --web          # سایت با اتاق گفتگو و اتاق کنترل
   python agent.py                # حالت متنی
   python agent.py --voice -y     # حالت صوتی کاملاً خودکار
   ```

## حالت وب — اتاق‌ها

با `python agent.py --web` سایت روی `http://127.0.0.1:8765` بالا میاد (فقط روی همین لپ‌تاپ در دسترسه):

- **💬 اتاق گفتگو:** چت با ایجنت، دیدن زنده دستورات و خروجی‌ها، دکمه میکروفون 🎤 برای حرف زدن، دکمه‌های تأیید برای هر دستور
- **🎛 اتاق کنترل:** وضعیت اتصال و کار، سرویس و مدل، تیک اجرای خودکار، تیک جواب صوتی، دکمه توقف، آمار جلسه و گزارش زنده

## نحوه کار

۱. کار تو به مدل AI فرستاده می‌شه
۲. مدل یک دستور برمی‌گردونه → ایجنت اجراش می‌کنه (یا اجازه می‌گیره)
۳. خروجی به مدل برمی‌گرده تا کار تموم شه (سقف ۳۰ مرحله)

## نکته امنیتی

حالت پیش‌فرض قبل از هر دستور تأیید می‌گیره. با `-y` یا تیک «اجرای خودکار» کنترل کامل به ایجنت می‌دی — روی کارهای حساس حواست باشه.
